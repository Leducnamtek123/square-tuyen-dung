# Security Policy — InfoHR (Square Tuyển Dụng)

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in InfoHR, please do NOT open a public issue.
Instead, report the issue directly to the security and engineering team:

- **Email**: security@infohr.vn
- **Response Time**: We acknowledge receipt of reports within 24 hours and aim to provide a detailed resolution timeline within 72 hours.
