# Reverse Engineering Great Design

## Goal
Train design judgment by decomposing high-quality references.

## Analyze in this order
1. First impression
2. Product story
3. Information architecture
4. Composition
5. Typography
6. Grid
7. Color
8. Imagery
9. Interaction
10. Motion
11. Responsive behavior
12. Technical implementation clues

## Important
Do not copy brand assets, proprietary illustrations, source code or exact compositions.

Extract transferable principles:
- hierarchy
- rhythm
- interaction pattern
- storytelling
- art direction
- technical approach

## Exercise
Recreate the underlying principle using a different product, brand and content.
