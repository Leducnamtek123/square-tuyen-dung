# Art Direction

## Objective
Create a distinct visual identity for the product.

## Process
Create a mini creative brief:
- product
- audience
- desired emotion
- personality adjectives
- visual references
- anti-references
- typography direction
- color direction
- image direction
- shape/material direction
- motion direction

## Visual thesis
Write one sentence:
"This product should feel like ______ because ______."

Every major visual decision must support that thesis.

## Avoid
- random gradients
- arbitrary glassmorphism
- excessive glow
- decorative 3D with no product relationship
- random oversized typography
- stock imagery that contradicts the brand
- copying a reference without understanding its purpose

## References
Use references for principles, not pixel copying.
Extract:
- composition
- rhythm
- hierarchy
- interaction idea
- art direction
- material/lighting language
