# Responsive Design

Do not design desktop and then merely shrink it.

Define:
- content priority by viewport
- grid transformation
- typography scaling
- navigation transformation
- image/canvas behavior
- interaction changes
- touch targets
- overflow strategy

Check:
- narrow mobile
- normal mobile
- tablet
- laptop
- large desktop

## Rule
Responsive design is a change in composition and priority, not only width.
