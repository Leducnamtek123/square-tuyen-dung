# Creative Coding

Use advanced visual technology only when it creates product value.

## Escalation ladder
1. CSS
2. SVG
3. Canvas
4. Framer Motion / GSAP
5. Three.js
6. WebGL/shaders

## Before using 3D/WebGL
Answer:
- Why cannot CSS/SVG solve it?
- What user understanding does it create?
- What is the performance budget?
- What is the mobile fallback?
- What is the reduced-motion fallback?
- What happens if WebGL fails?

## Quality
Creative coding should feel integrated with the product's visual language, not like a technology demo pasted into a website.
