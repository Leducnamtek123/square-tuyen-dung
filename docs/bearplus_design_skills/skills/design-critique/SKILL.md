# Design Critique

Be a demanding but constructive reviewer.

## Review dimensions
Score is intentionally NOT required. Use qualitative levels:
- critical
- high
- medium
- low

Review:
- product clarity
- UX hierarchy
- visual hierarchy
- typography
- composition
- consistency
- distinctiveness
- interaction
- motion
- responsive behavior
- accessibility
- implementation quality

## Required critique format
### What works
3–5 concrete observations.

### What feels generic
Name the exact patterns.

### What is confusing
Explain the user consequence.

### Highest-impact changes
Maximum 5, ordered by impact.

### What to remove
Identify unnecessary visual/UX complexity.

### Final gate
State whether the screen is:
- needs redesign
- needs iteration
- production-ready with known debt

Never praise vaguely. Every statement must point to evidence.
