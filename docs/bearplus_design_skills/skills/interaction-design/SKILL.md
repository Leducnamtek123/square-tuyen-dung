# Interaction Design

## Objective
Make interfaces understandable through behavior.

For each interactive element define:
- default
- hover
- focus
- pressed
- disabled
- loading
- success/error where relevant

## Affordance
Users should understand:
- what is clickable
- what changes
- what is selected
- what is draggable
- what is destructive
- what is currently happening

## Micro-interactions
Use interaction to:
- confirm actions
- expose relationships
- preserve context
- guide attention
- explain transitions

Never animate simply because a library supports it.
