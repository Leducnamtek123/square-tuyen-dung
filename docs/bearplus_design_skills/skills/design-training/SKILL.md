# Design Training

## Weekly practice

### Exercise A — Deconstruction
Choose one excellent website.
Break it into:
- structure
- visual system
- interaction system
- motion system
- product psychology

### Exercise B — Rebuild
Recreate one section from first principles.

### Exercise C — Transformation
Apply the learned principle to a different product.

### Exercise D — Critique
Run the design-critique skill.

### Exercise E — Reduction
Remove 20% of the UI without losing meaning.

## 12-week progression
Weeks 1–2: typography + spacing
Weeks 3–4: grid + composition
Weeks 5–6: UX + information hierarchy
Weeks 7–8: art direction + visual systems
Weeks 9–10: interaction + motion
Weeks 11–12: complete product + critique + responsive QA

## Learning rule
Do not measure progress by how many tutorials were watched.
Measure:
- quality of decisions
- ability to explain decisions
- speed of identifying problems
- ability to improve weak work
