# Accessibility

Accessibility is part of product quality, not a final checklist.

Check:
- semantic HTML
- keyboard navigation
- visible focus
- sufficient contrast
- accessible names for controls
- form labels/errors
- status announcements where needed
- touch target size
- reduced motion
- non-color-only meaning
- logical heading hierarchy
- screen-reader interpretation

Never sacrifice essential usability for visual novelty.
