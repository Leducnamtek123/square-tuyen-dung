# Visual Design

## Typography
Define:
- font family
- display/body pairing
- scale
- weight hierarchy
- line height
- letter spacing
- numeric/data typography
- responsive type behavior

Typography must communicate hierarchy, tone and density.

## Layout
Define:
- grid
- max width
- columns
- gutters
- section rhythm
- alignment anchors
- whitespace strategy

## Composition
Use:
- scale
- contrast
- alignment
- repetition
- proximity
- asymmetry when purposeful
- focal points
- negative space

## Color
Define semantic roles:
- background
- surface
- text
- muted text
- border
- primary
- accent
- success
- warning
- danger

Do not select colors independently for each component.

## Premium-design test
Ask:
- Does every element have a job?
- Is the hierarchy visible without reading?
- Is spacing intentional?
- Does the page have a visual rhythm?
- Could 20% be removed without losing meaning?
