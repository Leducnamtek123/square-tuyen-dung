# Agent Workflow

Use this sequence for any meaningful UI/product-design task.

## Phase 0 — Understand
Read requirements, existing code/design system, APIs, business rules and constraints.

## Phase 1 — Discover
Identify:
- users
- goals
- jobs
- primary flow
- constraints
- content
- states

## Phase 2 — Define
Produce:
- UX hierarchy
- IA
- page/flow map
- state map
- acceptance criteria

## Phase 3 — Art Direct
Produce:
- personality
- visual thesis
- references
- typography
- composition
- color
- imagery
- motion principles
- anti-patterns

## Phase 4 — Design
Build:
- tokens
- components
- compositions
- interactions
- responsive rules

## Phase 5 — Prototype
Validate the main user path before polishing secondary details.

## Phase 6 — Implement
Translate the approved system into production code.

## Phase 7 — Critique
Run:
- UX critique
- visual critique
- responsive review
- accessibility review
- implementation review

## Phase 8 — Iterate
Fix the highest-impact issues first.

## Phase 9 — Final gate
Do not say "done" unless:
- primary flow works
- states exist
- design is coherent
- responsive behavior is defined
- accessibility is acceptable
- no fake business logic was introduced
- visual QA was performed
