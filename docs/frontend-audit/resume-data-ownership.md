# Resume Data Ownership & Zero Fake Data Audit Matrix

## 1. Field-Level Ownership Breakdown
| Resume Field | Data Ownership Classification | Source / Persistence |
| :--- | :--- | :--- |
| `id` / `slug` | `BACKEND DATA` | Generated by backend database (`/api/v1/resumes/`). |
| `title` | `BACKEND DATA` | Stored in resume entity; editable via candidate profile modal. |
| `description` / `bio` | `BACKEND DATA` | Stored in resume entity; displayed in ProfilePage & CV viewer. |
| `resumeType` | `BACKEND DATA` | Enum (`WEBSITE` vs `ATTACHED`). |
| `templateId` | `BACKEND DATA` | Stored in resume entity; controls visual template renderer. |
| `skillsSummary` / `advancedSkills` | `BACKEND DATA` | Array of skill tags stored on server. |
| `academicLevel` | `BACKEND DATA` | Standardized backend choice enum. |
| `experience` | `BACKEND DATA` | Numeric years or experience object from backend choice configuration. |
| `isDirty` / Section Jump State | `LOCAL FORM STATE` | `React.useState` in `OnlineProfilePage` with `IntersectionObserver`. |
| `updatedAt` / `createdAt` | `BACKEND DATA` | Timestamp from backend server. |

## 2. Zero Fake Business Data Audit Verification
- **Resumes List & Detail**: Fully bound to real backend DTOs (`useResumes` hook).
- **Followed Companies**: Real company tracking via `companyService.getCompaniesFollowed`.
- **Notifications Hub**: Real unread counts and notifications list via `notificationService`.
- **Result**: **0 FAKE BUSINESS DATA FOUND** across candidate CV, company, and notification workflows.
